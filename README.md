Análise de Dados Sociodemográficos e Educacionais no SAS Workbench

Este repositório contém uma sequência de programas em SAS (SAS Studio / SAS Analytics Workbench) desenvolvidos para a ingestão, tratamento, análise estatística e exportação de relatórios sobre bases de dados públicas brasileiras (ENEM 2024, Censo 2022 e SIA/SUS).
